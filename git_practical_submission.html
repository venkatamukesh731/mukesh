Git Branching and Merging Practical

Objective

To create a Git repository, create branches, add and commit files, merge branches, create a merge conflict, resolve it, and push the repository to GitHub.

Commands and Operations Performed

1. Initialized the Git repository using git init.
2. Created the main branch.
3. Created a feature-header branch.
4. Created and added the header.html file.
5. Committed the changes using git commit.
6. Merged the feature-header branch into main.
7. Modified the same line in both branches to create a merge conflict.
8. Resolved the merge conflict manually.
9. Committed the resolved changes.
10. Pushed the main and feature-header branches to GitHub.

Result

Successfully created the branches, performed the merge, resolved the merge conflict, and uploaded the project to GitHub.
